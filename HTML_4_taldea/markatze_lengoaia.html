Markatze Lengoaiak: Webgunearen Egitura

Webgune estatiko hau HTML5 eta CSS3 erabiliz sortu da, eta GitHub Pages zein enpresaren IIS zerbitzarian argitaratzen da.

1. HTML egitura semantikoa

Orri guztiek egitura bera dute, hiru atal nagusitan banatuta:

  • <header>: goiburua, logotipoa eta nabigazio-menua (<nav>).
  • <main>: orriaren eduki nagusia, <section> eta <article> elementuetan antolatuta.
  • <footer>: enpresaren informazioa eta kontaktua (<address>).

2. Erabilitako elementu nagusiak

Webgunean erabilitako HTML elementuak
Elementua Erabilera Non
<h1> – <h3> Izenburuak, hierarkia argiarekin Orri guztiak
<ul>, <li> Zerrendak eta menua Orri guztiak
<table> Datu taularrak Zerbitzaria, Markatze lengoaiak
<img> Irudiak, alt testuarekin Hasiera (karrusela)
<a> Orrien arteko estekak Menua eta txartelak
<form> Saioa hasteko formularioa Saioa hasi

3. CSS estiloak

Estilo guztiak kanpoko fitxategi bakar batean daude (style.css), klase izen deskriptiboekin:

  • Aldagaiak (:root): kolore korporatiboak leku bakarrean.
  • Kutxa-eredua: margin, padding eta border propietateak.
  • Diseinua: display: flex menuan eta display: grid txarteletan.
  • Karrusela: CSS animazioa (@keyframes), JavaScript gabe.
  • Responsive: @media kontsultak mugikorretarako.

4. Irisgarritasuna

  • Hizkuntza zehaztuta (lang="eu").
  • Irudi guztiek alt testua dute.
  • "Joan edukira" esteka teklatu-erabiltzaileentzat.
  • Uneko orria menuan markatuta (aria-current).
  • Fokua ondo ikusten da teklatuarekin nabigatzean.
  • Formularioko eremu bakoitzak bere <label> du.
  • Karruselaren animazioa gelditzen da mugimendua murriztu nahi duten erabiltzaileentzat.
  • Testuaren eta atzeko planoaren arteko kontraste handia.
